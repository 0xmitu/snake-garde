# Snake Garden · 贪吃蛇

一个用原生 JavaScript 和 Canvas 制作的小型贪吃蛇游戏，使用 Node.js 提供本地静态服务。中文界面，零第三方运行依赖，支持键盘与触屏。

## 本机运行

需要 **Node.js 22 或更高版本**，以及支持 Canvas 和 JavaScript 模块的现代浏览器。

在项目目录运行：

```sh
npm ci
npm start
```

打开 [http://127.0.0.1:3000](http://127.0.0.1:3000) 开始游戏。按 `Ctrl+C` 停止服务器。

开发时可使用 `npm run dev`：Node.js 会在服务端代码变化后重启；页面修改后刷新浏览器即可。

默认监听 `127.0.0.1:3000`。如端口被占用，可通过 `PORT` 修改，例如 PowerShell：

```powershell
$env:PORT = '3001'
npm start
```

只有需要让局域网中的其他设备访问时，才显式设置 `HOST=0.0.0.0`，然后使用这台电脑的局域网地址访问。请按需配置防火墙；此项目不包含公网部署、TLS 或用户认证。

## 玩法与操作

吃到食物即可增长并获得分数；撞墙或撞到自己会结束本局。提供悠闲、经典、极速三档难度，吃到更多食物后速度逐渐提高。

| 操作 | 键盘 / 触屏 |
| --- | --- |
| 改变方向 | 方向键、`W A S D`、方向按钮，或在棋盘上滑动 |
| 开始 / 结束后再来一局 | `Enter` 或页面按钮 |
| 暂停 / 继续 | `Space` 或页面按钮 |
| 重新开始 | `R` 或页面按钮 |
| 选择难度、切换音效 | 页面控件 |

蛇不能立即掉头。每档难度分别记录本机最高分。

## 开发与验证

```sh
npm run check
npm test
```

`check` 检查 JavaScript 语法；`test` 使用 Node.js 内置测试运行器验证游戏规则和服务端行为。GitHub Actions 会在 Node.js 22 和 24 上运行这些检查。

```text
.
├── public/
│   ├── index.html       # 游戏页面
│   ├── styles.css       # 界面样式
│   ├── app.js           # 渲染、输入和浏览器交互
│   └── engine.js        # 独立的游戏逻辑
├── test/               # Node.js 内置测试
├── server.js           # 本地静态文件服务器
├── package.json
├── package-lock.json
├── LICENSE
└── .github/workflows/ci.yml
```

游戏逻辑与页面渲染分开，便于调整规则或添加新模式。欢迎通过 Issue 或 Pull Request 提交问题和改进；提交前请运行上面的检查。

## 隐私与开源准备

- 游戏不需要账号、API Key 或数据库，不接入统计、广告、远程排行榜或第三方 CDN。
- 最高分保存在当前浏览器的 `localStorage` 中，不上传到服务器。清除站点数据会移除这些本地记录；禁用浏览器存储时仍可游玩。
- 游戏音效由浏览器本地生成，可以关闭。
- 服务默认仅供本机访问；仓库不需要包含任何个人配置或凭据。

`.gitignore` 已排除常见环境文件、密钥、日志、依赖目录和本地工具配置，但它不会移除已经被 Git 跟踪的文件，也不能识别所有敏感信息。公开仓库前，请审查实际提交内容：

```sh
git status --short
git diff --cached --name-only
git diff --cached
```

确认只提交项目源代码、测试和文档，不包含令牌、私钥、个人路径、邮箱、日志或本地配置。若凭据曾进入提交历史，应先撤销或轮换凭据，再处理历史记录。
